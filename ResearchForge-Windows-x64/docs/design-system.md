# 界面设计系统 · 砚山

ResearchForge 的界面语言取宋画与文房：桌面是一方砚台色的书桌，工作区是一张纸，每个模块有一幅自己的山水。目标是安静、耐看、长时间使用不累，动效只在“进入、完成、确认”这些时刻发力，平时让位于内容。

后端结构与接口见 `docs/architecture.md`；本文只讲界面层（`platform/shared_ui/` 与各模块的样式）。

## 1. 原则

1. **纸与墨**：信息放在纸面上，强调靠墨色深浅和留白，不靠霓虹、发光或高饱和色块。
2. **一幅画一个模块**：研究构想 = 晨山（从一个问题出发），论文精读 = 湖景（静读一卷），文献地图 = 群岛与航线，提示词库 = 梅枝。
3. **动效有因果**：入场像墨迹晕开，确认像盖章，切换像翻页；轮询带来的重绘不重复播放。
4. **全部离线**：字体、插画、脚本随包提供，不请求任何外部资源，满足精读模块的严格 CSP。
5. **数据与视觉分离**：页面脚本只依赖元素 ID；视觉通过类名、`data-*` 钩子与设计令牌表达。

## 2. 色彩

所有颜色都是 `tokens.css` 中的变量，浅色与深色各一套；`data-theme="light|dark"` 覆盖系统设置。外观默认“跟随时间”：`boot.js` 在首屏前按本地时间（日出、日落随季节近似变化，不读取位置）设置 `data-theme`，入夜（日落后约半小时）自动转深色，清晨前转回浅色；清晨与傍晚另设 `data-rf-tone="dawn|dusk"`，只微调纸色、水墨晕染与题图天空（晨雾偏青、傍晚偏杏色）。`shell.js` 每分钟及回到页面时复核，深浅切换时新外观缓慢淡入。外观按钮依次切换：跟随时间、浅色、深色、跟随系统。

| 角色 | 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|---|
| 书桌 | `--rf-desk` | #ebe5d8 | #100f0d | 页面底色、侧栏所在 |
| 纸面 | `--rf-bg` / `--rf-surface` | #faf7f1 / #fffdf8 | #181714 / #201e1a | 工作区、卡片 |
| 墨 | `--rf-text` … `--rf-text-4` | #2a2722 → #978f82 | #ece6da → #7a7366 | 正文到辅助文字 |
| 松石 | `--rf-accent` | #4a7564 | #8cb7a2 | 主操作、选中、完成 |
| 赭石 | `--rf-ochre` | #a9774a | #d3a676 | 次级强调、编号、标签 |
| 朱砂 | `--rf-cinnabar` | #b2513c | #e08e78 | 印章、品牌、第一名 |
| 黛蓝 | `--rf-indigo` / `--rf-info` | #3f5c76 | #9bb6cf | 提示信息 |
| 藤黄 / 胭脂 | `--rf-warn` / `--rf-danger` | #94661a / #a4473a | #e1b469 / #ec9583 | 需处理、错误 |

插画颜料（`--rf-art-*`）与背景水彩（`--rf-wash-*`）同样随主题切换。正文与背景对比度不低于 WCAG AA。

## 3. 字体与排版

- **标题**：`--rf-font-display` / `--rf-font-serif`，首选随包的 **RF Song**（思源宋体 SemiBold 子集，OFL，已按要求改名）。核心分片含界面全部用字与 GB2312 一级汉字，扩展分片含二级汉字，浏览器按 `unicode-range` 只下载用到的分片；本机已装思源宋体时直接使用本地字体。
- **正文**：系统无衬线（苹方 / 微软雅黑 / 思源黑体）。
- **数字**：表格与计数使用 `tabular-nums`；大号统计数字用宋体。
- 层级：`--rf-text-hero`（题图标题）、`--rf-text-2xl`（页面标题）、`--rf-text-xl`（区块标题）、`--rf-text-base` 14.5px（正文）。题图标题只在标点处换行（`word-break: keep-all`）。

## 4. 布局

```text
┌ 书桌 (desk + 水彩) ───────────────────────────────────────┐
│ 侧栏 268px        ┌ 纸面 .workspace（圆角 26px，悬浮阴影）─┐ │
│ 印章品牌          │ 顶栏：滚动前透明，滚动后磨砂            │ │
│ 模块导航（纸签）  │ 山水题图 .rf-hero（顶栏压在画上）        │ │
│ 新建 / 历史       │ 内容卡片叠压在题图下缘                    │ │
│ 设置 / 外观 / 动效│                                           │ │
└────────────────────┴───────────────────────────────────────┘ ┘
```

- 窗口滚动（不是内部滚动容器），顶栏 `position: sticky`，纸面 `overflow: clip` 不破坏粘性定位。
- 860px 以下：侧栏变抽屉，纸面全宽无圆角；所有网格降为单列。

## 6. 动效系统

### 令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--rf-ease-ink` | cubic-bezier(.16,.84,.3,1) | 墨迹晕开式入场 |
| `--rf-ease-spring` / `-soft` | `linear()` 阻尼弹簧近似 | 按钮、分段指示、导航纸签 |
| `--rf-dur-1…5` | 120 / 200 / 320 / 520 / 900 ms | 微交互到场景入场 |
| `--rf-stagger` | 45 ms | 列表逐项延迟 |

### 编排

- **页面入场**：题图天空 → 太阳/月亮升起 → 远中近山依次上浮 → 标题逐字由模糊到清晰 → 输入卡片展开。
- **跨模块**：浏览器跨文档视图过渡。侧栏交叉淡化，导航纸签滑到新模块，背景水彩不中断，主内容按模块顺序左右滑入。
- **页内**：构想、评审等阶段切换使用 `rf-stage` 过渡；新到的构想卡片展开（按 `data-rf-key` 只播放一次）。
- **反馈**：复制成功盖“已复制”朱砂印；精读完成横幅的印章落下；外观切换以按钮为圆心晕染开新主题。
- **持续运动**（只在“完整”模式）：水彩缓慢流动、雾带漂移、芦苇摇曳、飞鸟、落梅、群岛间小船往返。

### 偏好与降级

| 模式 | 触发 | 行为 |
|---|---|---|
| 完整 | 默认 | 全部动效 |
| 简洁 | 侧栏动效按钮 / 命令面板 | 保留过渡，停止循环运动，视差减弱，水彩静止 |
| 关闭 | 同上，或系统“减少动态效果” | 不播放动画与页面过渡，水彩静态绘制 |

用户显式选“完整”可以覆盖系统的减少动态效果设置。

### 动效引擎钩子（`motion.js`）

| 钩子 | 作用 |
|---|---|
| `data-scene="dawn|lake|isles|plum"` | 生成山水题图（遮罩图层、日月、飞鸟、航线、梅花） |
| `data-rf-split` | 标题逐字入场 |
| `data-rf-reveal` / `data-rf-stagger` | 进入视口时揭示（子元素依次） |
| `data-rf-animate`（`always` 可选） | 列表新增项展开；有键（`data-task-id` 等）时只对新键播放 |
| `data-rf-magnetic` | 主按钮被指针轻轻吸引 |
| `data-rf-segmented` | 分段滑动指示器 |
| `RFMotion.countTo / stampAt / progress` | 数字滚动、印章反馈、阅读进度线 |

## 7. 插画管线

插画分两步：先程序化构图，再用 SDXL 补上真实笔墨。

`tools/paint_art.py` 用 numpy + OpenCV 程序化绘制（固定随机种子，可复现）：

- 山脊：多倍频噪声轮廓 × 构图包络，向下渐淡入雾；边缘积墨、斑块状皴擦纹理。
- 笔触：模拟毛笔多根鬃毛，干笔在边缘和收尾处断开（飞白），用于芦苇、梅枝、水纹。
- 输出是**灰度透明度遮罩**（WebP），由 CSS `mask-image` + 颜色令牌着色，因此浅色是晨雾青山，深色自动成为月下墨山。
- 需要动画的点数据另存 JSON：群岛锚点与航线（`isles.json`）、梅花位置与开放状态（`plum.json`），由页面用 SVG 绘制。

**笔墨精修（`tools/refine_art.py`）**：程序化图层负责构图，Stable Diffusion XL 负责笔墨质感。脚本在内存中重新生成同一套程序化图层，把每层画成“纸上墨”交给 SDXL 图生图（强度 0.5–0.72，按图层设定主题词与种子），再全分辨率轻修一遍；结果换算回墨色浓度遮罩，裁到该层原有轮廓稍外的范围内，并用 gamma 曲线保持原来的整体墨量。所以视差分层、深浅色着色和 JSON 锚点都不受影响。雾、水面倒影和水纹保留程序化的柔和效果；群岛强度较低，使岛形与倒影一致。

- 同一脚本用文生图画四幅空状态小景（研究：山亭松径；精读：线装书与笔；文献地图：孤舟远屿；提示词库：梅枝），只保留与画面中心相连的墨迹，自动去掉模型附带的题款与印章，四周渐隐。
- 运行环境：本机 CUDA 显卡，系统 Python 装 torch、diffusers 0.35、opencv-python、Pillow；权重为 `stabilityai/stable-diffusion-xl-base-1.0`（fp16）与 `madebyollin/sdxl-vae-fp16-fix`，从本机 Hugging Face 缓存离线加载。这些都不进入软件自带的运行环境，分享包只含生成好的 WebP。
- 顺序：`python tools/paint_art.py`（程序化底稿与 JSON）→ `python tools/refine_art.py [--only dawn,vignettes] [--preview 目录]`。种子固定，重跑得到相同文件。生成前的程序化版本可随时用 `paint_art.py` 复现。
- SDXL 权重许可为 CreativeML Open RAIL++-M，生成的图片可随软件分发，见 `THIRD_PARTY_NOTICES.txt`。

新增一幅题图：在 `paint_art.py` 加一个 `scene_*` 函数并注册，在 `refine_art.py` 的 `LAYERS` 里为需要笔墨的图层写主题词与强度，依次运行两个脚本；在 `motion.js` 的 `SCENES` 中登记图层顺序、颜色令牌与景深；页面放 `<div data-scene="名称">`，并确认各图层文件都已生成。

## 8. 性能与可访问性预算

- 背景水彩在不超过 560px 的缓冲区渲染、约 30fps，页面隐藏时停止；实测 1440×900 下空闲、指针视差、滚动均稳定 60fps。
- 视差只更新可见题图的三个 CSS 变量；入场动画使用独立的 `translate/scale/opacity`，不与视差的 `transform` 冲突。
- 所有交互元素保留可见焦点环；对话框、命令面板、菜单支持键盘；装饰元素 `aria-hidden`。

## 9. 验收清单

修改界面后至少确认：

1. 用 `run.py --workspace <临时目录>` 启动隔离实例，检查各模块与 `/setup` 在浅色、深色、375px 宽度下的布局，以及页面引用的资源和题图图层都能加载。
2. 动效设为“关闭”时内容完整可见；“完整”时控制台无报错、无明显掉帧。
3. 新增文字后重跑 `tools/build_fonts.py`，确认没有缺字。
