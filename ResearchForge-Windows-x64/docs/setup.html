开始

三种开始方式

  1. 一

    直接精读一篇

    进入论文精读，打开“共享 API 设置”填写自己的密钥、模型和接口。上传 PDF / MD / TXT 后开始分析，不需要先建摘要库。

    打开论文精读
  2. 二

    研究构想与检索

    按根目录 README 填入自己的摘要 CSV，再点击准备检索。Ollama 和嵌入模型已经内置。只生成构想而不检索时，可把筛选数量设为 0。

    打开研究构想
  3. 三

    积累个人提示词

    直接新建，或把自己的文件放入配置的 prompt_import 目录后导入。收藏和编辑都不需要 API。

    打开提示词库
全文

连接自己的本地全文

默认将论文放到 user_data/papers/。有正式题名、年份和 DOI 时，在元数据模板中一并填入，再运行：

runtime\python\python.exe tools\index_fulltext.py --metadata 我的全文元数据.csv

索引完成后，到精读页面搜索并预览。研究构想中的文献引用也可据此找到原文。元数据不足时只按文件名建立索引，不会猜出作者或年份。

配置

配置与架构

根目录 config.example.json 可复制为 config.json，用于修改数据位置、研究阶段模型、语言范围和端口。提示词管理员账号为 admin，随机密码显示在启动窗口，并保存在当前数据目录下的 admin-password.txt。

此版本默认仅供个人在本机使用。运行后 user_data 包含你自己的私有内容，不能直接连同这些数据再次分享。
