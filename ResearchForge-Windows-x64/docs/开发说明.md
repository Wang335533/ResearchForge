# ResearchForge 共享空白版

这是研究工作台便携版的开发说明，保留研究构想、论文精读、文献地图、提示词库和本地文献连接。首次启动没有论文、摘要、研究记录、个人提示词或 API 密钥。运行环境已由便携包提供。

先双击根目录的「架构说明.html」了解结构，也可阅读「ResearchForge架构讲解.pptx」。HTML 完全离线，不请求外部字体、脚本或服务。

## 启动

本便携版已随包安装运行环境，直接使用根目录的启动入口。详见根目录 README.md。下面的配置和功能结构保持一致。

## 填入自己的配置

1. 把 `config.example.json` 复制为 `config.json`。相对路径以本分享文件夹为基准；也可填写自己明确指定的绝对路径。不要把密钥写入该文件。
2. 打开「论文精读 → 共享 API 设置」，填写自己的接口地址、API 密钥、模型与思考模式。初始 DeepSeek 地址只是公开服务地址，密钥为空。可添加其他兼容 Chat Completions 的服务。实际可用模型和额度以所选供应商账户为准。
3. `config.json` 的 `stages.gen / judge / opt` 分别配置构想生成、评审、优化使用的 provider、model、temperature、thinking。provider 要与共享 API 设置中的标识一致。三个阶段默认使用同一个 DeepSeek 配置。更改阶段配置后重启；仅修改密钥或接口地址时由共享配置即时读取。精读页面的模型与额度只控制精读。
4. 设置提示词：研究构想的运行提示词位于 `platform/研究流水线Web/prompts/`，页面修改需要管理员登录。账号 `admin`，随机密码在首次启动的终端和 `user_data/admin-password.txt` 中。论文精读运行提示词可在精读页面编辑。个人积累的「提示词库」与运行提示词分开管理。

密钥仅在本机 `user_data/reader/settings.json` 中保存，浏览器不回显。分享包没有默认密钥、已登录会话或固定管理员密码。

## 摘要检索库与本地全文库

两套索引承担不同工作，不能相互替代。

### 摘要库：供研究构想 S3 使用

复制 `examples/corpus.template.csv` 为 `user_data/corpus.csv`，填入自己有权使用的文献元数据。模板只有表头，没有任何真实或演示论文。UTF-8 CSV 列如下：

|列|含义|
|---|---|
|ut|不重复的稳定编号，例如自己定义的 LOCAL:001|
|title / authors / source_title|原题名、作者、期刊|
|publication_year / doi|四位发表年份、DOI；缺失 DOI 可留空|
|abstract / keywords_plus|完整摘要、关键词|
|document_types|Article 或 Review；多项用竖线分隔|
|language / source_database|zh 或 en；来源名称|

CNKI Journal Record 兼容路径要求编号以 CNKI: 开头。系统不会下载或补造真实摘要。

摘要混合检索使用包内 Ollama 和嵌入模型。点击平台「准备检索」时会导入 CSV 并计算向量。默认模型已经随包提供。首次启动默认 `auto_prepare=false`，不启动模型准备。空 CSV 不触发下载。

默认中英文等额检索：每种语言最多25篇，其中优先取近期最多10篇，总计最多50篇；如果一方不足，双方取共同可提供的数量。只有英文库时，把 `languages` 改为 `["en"]`；只有中文库用 `["zh"]`，每次最多25篇。数量不足如实返回，不补造文献。只做精读无需 Ollama 或摘要库。

### 全文库：供搜索、预览、导入精读使用

将 PDF / MD / TXT 放入 `user_data/papers/`，或在 config.json 的 papers 配置你自己的目录。可用 `examples/fulltext-metadata.template.csv` 创建元数据清单，path 填相对于全文目录的路径，其余列填准确题名、作者、年份、期刊、DOI、摘要与关键词。

```bat
runtime\python\python.exe tools\index_fulltext.py --metadata 我的全文元数据.csv
```

没有元数据也可以运行 `runtime\python\python.exe tools\index_fulltext.py`，此时只用文件名作为题名、摘要留空，匹配质量有限。工具只读原文件，索引写入当前分享版的数据目录；不调用模型。新增或修改文件后重新运行。界面的「刷新」只刷新现有索引。扫描 PDF 需要先在外部做 OCR。

研究构想的引用根据 DOI、准确题名和年份对应到全文索引；明确匹配可直接载入，版本冲突须核对。载入不调用分析 API，点击「开始精读」才生成报告。摘要匹配不能替代全文证据。

## 私有数据与备份

所有运行数据默认在 user_data：research 保存构想任务与导出；reader 保存上传快照、精读任务、地图与提示词集合；abstract-index 是摘要向量索引；fulltext-index.sqlite3 是全文索引；papers 与 prompt-import 是用户自己放入的材料。

首次入库的地图定位是精读后的额外一次模型请求。超长精读可能先分段提取证据，再一次撰写完整报告。网络或截断错误不会自动重复整次生成。研究构想阶段若缺少允许补全的字段，原有机制最多额外补全一次；手动继续会复用已完成步骤；浏览器刷新不会停止后台任务。

个人提示词可以直接新建，也可放在配置的 prompt_import 文件夹后点击「从配置文件夹导入」。默认目录为空，程序不会扫描桌面。地图和提示词库各自提供备份恢复。

运行过后的整个目录含有自己的私有数据，不应直接转发。分享初始副本或重新清理 user_data、config.json、日志、备份和自定义运行提示词后再共享。`.gitignore` 防止常见误提交，但它不是脱敏工具。

## 开发入口

详见「架构说明.html」中的模块与接口。核心路径：

- `platform/研究流水线Web/server.py`：研究构想接口、统一主服务。
- `platform/研究流水线Web/research_tasks.py`：分阶段任务、并发额度、断点。
- `platform/论文检索/retrieval_service.py`：摘要导入、向量准备、检索编排。
- `platform/paper_reader/app.py`：精读入口与完整报告生成。
- `platform/paper_reader/memory.py`：永久文献卡片、分类、版本、关系。
- `platform/paper_reader/prompt_library.py`：提示词集合、历史版本与备份。
- `platform/paper_reader/research_bridge.py`：构想引用到本地全文的连接。
- `run.py`：独立启动、路径隔离、配置与管理员初始化。
- `tools/index_fulltext.py`：接收者自己的全文建索引工具。
- `platform/shared_ui/`：四个模块共用的界面层，由主服务在 `/ui/` 提供（精读模块单独运行时也会提供）。
  - `tokens.css`：颜色、字体、圆角、阴影与动效变量，含浅色与深色两套；页面样式只引用这些变量。
  - `shell.css`：侧栏、模块导航、顶栏、按钮、对话框、提示条、命令面板与页面过渡。
  - `boot.js`：在首帧前应用外观设置，并为跨页过渡设置方向。
  - `shell.js`：外观切换、移动端侧栏遮罩、页内过渡，以及 Ctrl/⌘+K 命令面板（只读取本机接口，不调用模型）。
  - `icons.svg`：Lucide 图标合集，页面用 `<use href="/ui/icons.svg#i-名称">` 引用。

  模块之间切换使用浏览器原生的跨页视图过渡；不支持的浏览器会直接切换页面。系统开启“减少动态效果”后，所有动画都会关闭。

修改代码后，先用合成材料和模拟 API 验证，不要填入真实密钥。

## 使用边界

这是面向单人的本地研究工作台，默认仅监听回环地址。它没有实现多用户权限、团队隔离或公共服务器部署。模型输出需要学术核查；模型调用会把所需正文、研究说明或摘要发送至配置的服务商。兼容接口差异、模型权限及费用由使用者确认。

分享版保留应用代码结构与 KaTeX 许可文件；已打包 Python、Ollama 和公开嵌入模型，但不包含论文语料，也不替原项目新增开源授权声明。
