接收者如何搭建

  1. 完整解压并启动双击对应系统的启动入口，内置 Python 与依赖。自动选择可用端口，仅监听本机。
  2. 填写自己的 API在“论文精读 → 共享 API 设置”中填写密钥、地址与模型。三个研究阶段的模型在 config.json 中选择。
  3. 选择需要的数据能力只读单篇论文可直接上传。研究构想的检索需要自己的摘要 CSV，Ollama 与模型已经内置；本地全文搜索需要自己的文件索引。
  4. 积累自己的研究资产编辑运行提示词、保存报告、建立文献卡片与提示词集合；定期导出备份。

通用终端启动

runtime\python\python.exe -I -B portable.py

本版本直接双击 START-WINDOWS.cmd。无需执行安装脚本。

填写全文元数据后建索引

runtime\python\python.exe tools\index_fulltext.py ^
  --metadata 我的全文元数据.csv

模板在 examples 中，只有字段名。未填元数据时按文件名建立题名索引；匹配质量与元数据准确性有关。

开发者从哪里扩展

改变研究方法

先改阶段提示词与精读报告提示词。涉及结构字段时，同时改服务端校验、持久化与前端显示。

接入新的数据

摘要导入在检索服务中扩展；本地全文导入在全文索引工具中扩展。稳定编号与真实来源定位应继续保留。

替换生成接口

先验证 Chat Completions 兼容性、思考参数、上下文与结束标记。接口适配与模型参数分开管理。

任务、成本与证据边界

研究任务逐阶段保存，支持停止与手动继续；原有完整结果可复用。报告撰写使用一次调用，超长文档证据提取及首次地图整理会增加调用。研究构想阶段若缺少允许补全的字段，原机制可能额外补全一次；不代表所有错误都会自动修好。

文献关系初始为待核实建议；学术贡献、识别假设和后续研究仍需人工判断。此版本面向个人本地使用，尚不是具有账户权限与团队隔离的公共云服务。
